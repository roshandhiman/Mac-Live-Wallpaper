# LiveWallpaperApp

LiveWallpaperApp is a macOS application that allows you to set **live video wallpapers** on your desktop.  
It replaces static wallpapers with looping videos for a more dynamic and personalized desktop experience.  

## Features
- Play videos as desktop wallpapers  
- Lightweight and minimal resource usage  
- Works with multiple video formats  
- Simple and clean UI  

## Requirements
- macOS (tested on macOS 13+ and Apple Silicon/M1/M2/M3/M4 Macs)  
- Xcode 15 or later (for building the app)
