# 🎬 LiveWallpaperApp

LiveWallpaperApp is a macOS application that lets you set **live video wallpapers** on your desktop.  
It replaces static wallpapers with looping videos for a more dynamic and personalized experience.

---

## ✨ Features

- 🎥 Play videos as desktop wallpapers  
- ⚡ Lightweight and minimal resource usage  
- 📂 Supports multiple video formats  
- 🧼 Simple and clean UI  

---

## 📋 Requirements

- macOS 13+ (Apple Silicon: M1 / M2 / M3 / M4)  
- Xcode 15 or later  

---

## 🚀 Installation & Usage

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/LiveWallpaperApp.git
cd LiveWallpaperApp
```

---

### 2️⃣ Open in Xcode

- Open **Xcode**  
- Click **"Open a project or file"**  
- Select `LiveWallpaperApp.xcodeproj`  

---

### 3️⃣ Build & Run

- Select your **Mac** as the target device  
- Click the **▶️ Run (Build) button** in Xcode  

---

### 4️⃣ Set Live Wallpaper

- After the app launches:
  - Click **"Select Video"**  
  - Choose a video from your system  
  - The video will start playing as your desktop wallpaper  

---

## ⚙️ How It Works

- Uses macOS rendering layers to play video in the background  
- The selected video loops continuously as your wallpaper  

---

## 📌 Notes

- ✅ Use **MP4 format** for best compatibility  
- ⚡ Lower resolution videos give better performance  
- 🔋 High-resolution videos may consume more battery  

---

## 🛠 Tech Stack

- Swift  
- AppKit (macOS)  
- AVFoundation
